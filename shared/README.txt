睿洋機電品牌開場

1151011、1151011-01、1151011-02 的首頁共用 brand-intro.css 與 brand-intro.js。
標誌取自各版頁首，無須另行複製或修改圖片。

動畫流程：
0.15 秒起顯示品牌引言，0.25 秒起由左向右揭示標誌。
0.85 秒起顯示中文標語與英文品牌名稱。
2.5 秒起向上揭幕退場，約 3.4 秒完成；3.8 秒為異常情況的解除上限。
細線為品牌動畫，不代表圖片或網路資源的實際下載進度。

使用方式：
首次開啟無錨點的首頁會自動播放；帶有 #contact 等錨點時不遮擋目標內容。
右下角「略過開場」或 Escape 可立即結束，首頁形象區右上角可重播。
使用者設定減少動態效果時不播放開場，也不顯示重播按鈕。
開場使用原生 dialog 管理焦點與背景互動；結束後解除捲動鎖定並恢復焦點。
開場期間停止首頁輪播，結束後保留原有的手動暫停、游標與焦點暫停行為。

部署：
保留版本資料夾與 shared 資料夾的同層結構，三版均以 ../shared/ 引用共用檔。
如需將某版單獨部署為網站根目錄，請把這兩個動畫檔放到該版的 shared/
資料夾，並將該版 index.html 的兩個 ../shared/ 路徑改為 ./shared/。
